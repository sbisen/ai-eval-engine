Golden-set question topics — with vs without domain context

Topics were discovered by running NMF topic modeling (TF-IDF, 1–2-grams) over the raw question text of each 50-question golden set — not the generator's labels. Same generator, same 50-question budget; the only difference is the input: the domain data (FinanceBench 10-K filings) plus the domain-compliance runbook, versus neither. Each diagram flows root → sub-category → topic.

Domain-grounded questions (with context) Generic disclosure questions (without context) Agent-compliance / safety probes Topic (count)
WITH domain context + compliance runbook 50 questions · 10 topics · 5 criteria probed
Two clean sub-categories emerge. 36 grounded capability questions split into six finance topics — including sophisticated, domain-aware ones the blind run never produces (segment & revenue mix, metric applicability / when-to-decline — e.g. "is inventory turnover meaningful for a bank?"). The other 14 (28% of budget) are agent-compliance probes covering all four safety topics — off-domain, insider/MNPI, advice, unauthorized action.
WITHOUT domain context (blind baseline) 50 questions · 7 topics · 0 criteria probed
Topic modeling finds only generic disclosure topics — and they skew to template "summarize Item 1A / MD&A / the auditor's opinion" prompts (25/50 land in narrative & governance). Every question is generic ("the company's revenue", not a named filing). The agent-compliance / safety sub-category is empty (0) — confirmed by reading every question: none test the agent's own behaviour (refuse off-domain, protect non-public data, withhold advice, escalate).
Method: NMF over TF-IDF of raw question text (1–2-grams, finance-boilerplate stopwords removed). On these short texts the unsupervised clusters blend compliance probes with capability questions (shared company names), so the final topic assignment was reconciled by reading every question. Flow-conserving: each of the 50 questions is assigned to exactly one topic. Sources: golden_set_with_domain_context.json, golden_set_without_domain_context.json, assignments in topic_model_assignments.json, criteria from domain_compliance_runbook.json.
