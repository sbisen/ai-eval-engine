Baseline (no framework) vs AI Eval Engine — what each golden set can cover

The two baseline columns are the no-framework reality, not a measured run: with no golden set there is nothing to evaluate against; a hand-authored set covers only what someone remembered to write and drifts as data and prompts change. The framework column is measured — the generated with-context golden set. All 50 questions are accounted for below: 36 domain-capability questions (of which 5 are edge-case/decline) + 14 compliance/safety probes = 50.
